# Loghi ufficiali delle integrazioni

L'app mostra i loghi solo per indicare con quali servizi funziona, senza modificarli.
Ogni marchio ha linee guida proprie: scarica il file dal kit ufficiale, accettandone i termini,
salvalo qui come `<id>.png` (quadrato, sfondo incluso, almeno 120×120 px) e registralo in
`src/integrations/logoAssets.ts`.

| id | Marchio | Fonte ufficiale |

| health_connect | Health Connect | developer.android.com → Health Connect → brand guidelines |
